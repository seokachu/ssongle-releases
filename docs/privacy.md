# 개인정보 안내 (초안)

> 정식 개인정보처리방침은 서비스 공개 전에 확정해 이 문서를 갱신합니다. 아래는 지금 설계 기준으로 무엇을 어디에 두는지 적은 안내입니다.

## 참가자 (로그인하지 않은 경우)
- 남기는 것: **닉네임**(1~12자)과 그 판의 점수 · 등수
- 보관: 게임이 끝나면 사라집니다. 계정도 없고, 다음 판으로 이어지지 않습니다

## 로그인한 참가자 · 방장
- 로그인 방법: 구글 계정으로만
- 남기는 것: 구글 계정 식별자, 닉네임, 누적 점수 · 포인트, 꾸민 쏭나물 조합, 최근 판 기록
- 쓰는 곳: 마이페이지에서 내 기록과 쏭나물을 보여 주고, 다음 판에서 같은 모습으로 참가하게 하는 데만 씁니다
- 로그아웃해도 기록은 계정에 남고, 다시 로그인하면 이어서 씁니다
