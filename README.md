# 쏭글쏭글 🌱

**4컷 만화만 보고 노래를 맞혀요.**

마스코트 쏭나물이 노래 가사를 4컷 만화로 연기합니다. 큰 화면에 만화가 뜨면, 각자 폰에서 보기 4개 중 노래를 고릅니다.
카훗이나 골든벨을 떠올리면 됩니다 — 문제가 "만화"라는 것만 다릅니다.

| 구분 | 여느 노래 퀴즈 | 쏭글쏭글 |
|---|---|---|
| 문제 | 전주 듣기 · 가사 빈칸 | 쏭나물이 연기하는 **4컷 만화** |
| 참가 | 앱 설치 · 가입 | **QR 찍고 이름만** — 가입도 설치도 없음 |
| 곡 풀 | 진행자가 직접 고름 | 연도 하나만 고르면 그 해 TOP100에서 출제 |
| 내 캐릭터 | 없음 | 로그인하면 쏭나물을 **꾸미고** 점수가 남음 |

## 어떻게 노나요

**방장 (PC)**
- 로그인하고 연도 카드 하나를 누르면 방이 만들어집니다. 기본은 섞어서 10문제.
- 난이도 · 문제 수(5/10/15/20) · 장르(아이돌 · 보컬 · 밴드·인디 · 힙합·R&B)만 살짝 손볼 수 있습니다.
- 큰 화면(TV · 빔프로젝터)에 대기실을 띄우면 QR과 입장 번호 6자리가 뜹니다.

**참가자 (폰)**
- QR을 찍거나 입장 번호를 넣고, 이름만 정하면 들어옵니다.
- 큰 화면의 만화를 보고 폰에서 보기 4개 중 하나를 고릅니다. 빠를수록 점수가 높습니다.
- 정답이 공개되면 누가 뭘 골랐는지, 지금 몇 등인지 보이고 자동으로 다음 문제로 넘어갑니다.
- 마지막엔 시상대. 로그인한 참가자는 점수가 남고, 포인트로 쏭나물을 꾸밀 수 있습니다.

**쏭나물 꾸미기**
- 모자 · 안경 · 목 · 손 아이템과 몸 색을 따로 골라 조합합니다. 고른 모습이 대기실 이름표 · 순위표 · 시상대에 그대로 보입니다.

## 이 저장소는

쏭글쏭글의 **릴리즈 안내와 사용자 지원**을 위한 공간입니다. 소스 코드는 비공개 저장소에서 관리합니다.

- **[릴리즈](../../releases)** — 버전별로 무엇이 바뀌었는지

- **[문의 · 버그 신고](../../issues)** — 이슈로 남겨 주시면 확인합니다

## 개인정보

- 참가자는 **닉네임만** 남깁니다. 로그인하지 않으면 그 판이 끝난 뒤 점수는 남지 않습니다.
- 로그인은 구글 계정으로만 하고, 점수 · 포인트 · 꾸민 쏭나물을 계정에 보관하는 데만 씁니다.
- 자세한 내용은 [개인정보 안내](./docs/privacy.md)에.
